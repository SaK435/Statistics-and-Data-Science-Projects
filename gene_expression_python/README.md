# Gene Expression Data Cleaning and Merging

This project is a practical exercise in data cleaning and data management. I used Python, Visual Studio Code and GitHub to clean raw datasets and combine them into one file that is ready for analysis.

## Data

The datasets were provided for practice. There are five in total:

* Four datasets with anthropometric measurements from different countries
* One dataset with gene expression values for groups of individuals

The raw files are in `gene_expression/data`. The final merged dataset is saved in `gene_expression/out`.

## What the code does

1. Reads and cleans each dataset
2. Merges all five datasets into a single dataset
3. Saves the result in the `out` folder for later analysis

## Analysis

After cleaning and merging, I took a short look at the data:

* The distribution of Body Mass Index (BMI) across the different populations
* Whether BMI appears to be related to the expression of certain genes

## Tools

Python, Visual Studio Code, GitHub
